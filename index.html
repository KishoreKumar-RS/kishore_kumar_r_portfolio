Project 02 Live Deployed

E-Bike Navigation with Intelligent Parking Assistance

A mobile-first web platform that transforms e-bike commuting with real-time routing, weather-aware recommendations, and in-browser ML-powered obstacle detection — no server required for inference. By running TensorFlow.js + COCO-SSD directly on-device, the system identifies nearby vehicles and pedestrians in real time and triggers voice alerts. Four distinct external APIs are orchestrated seamlessly behind a single cohesive interface.

Computer Vision
Problem

Industrial and surveillance environments need autonomous collision risk monitoring without dedicated hardware or constant human supervision.

Solution

Python + OpenCV pipeline with real-time object detection, trajectory risk scoring, and image capture — piped instantly to Telegram with zero cloud infrastructure overhead.
